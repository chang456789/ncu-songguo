## B. 要留著（不刪）

| 程式 | 原因 |
|---|---|
| `#/food`、`#/nav`、`#/news`、`#/more`、`#/online` 等舊網址的轉址 | 別人存的書籤、分享出去的連結還會用到 |
| `foodPage()`、`navPage()` | 地圖分頁的兩個圖層就是用它們畫的 |
| `go("food")`、`go("nav")` 的轉換 | AI 卡片、搜尋、通知都會用到 |
| 天氣頁 `weatherPage()`（`#/weather`） | 不在選單，但問松果的天氣卡片、今日松果會打開它 |
| `feedItems()` | 新首頁的「動態」在用 |
| 浮動的問松果視窗（`.ai-panel`、`.ai-fab`） | 手機上首頁以外的頁面還在用 |
