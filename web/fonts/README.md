# 字型

## 俐方體11號 Cubic 11（Ver. 1.500）
- 檔案：`Cubic_11.woff2`
- 來源：作者的 GitHub https://github.com/ACh-K/Cubic-11 （`fonts/web/Cubic_11.woff2`，commit 4c566f7）
- 授權：SIL Open Font License 1.1，授權全文在 `OFL-Cubic-11.txt`。
  依授權規定，散布字型時必須附上授權檔，所以請不要刪掉 `OFL-Cubic-11.txt`。
- 用途：只用在標題（h1–h3）、數字（公車時間、溫度等）和按鈕文字，設定在 `web/ui.css`。內文維持原本的字型。
- 字型從本站載入，不使用外部 CDN。
